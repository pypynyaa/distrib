# Insomnia Market

MVP музыкальной дистрибуции: React-интерфейс артиста, отдельный админ-кабинет команды и Python/FastAPI API с SQLite.

## Запуск

```bash
npm install
npm run dev
```

В отдельном терминале:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r backend/requirements.txt
uvicorn backend.main:app --reload --port 8000
```

Демо-аккаунты API:

- артист: `artist@insomnia.market` / `insomnia`
- владелец: `owner@insomnia.market` / `admin`

В GitHub Pages демо-режиме эти же аккаунты работают без API:

- `artist@insomnia.market` открывает обычный кабинет артиста;
- `owner@insomnia.market` открывает админ-сайт команды.

Документация API после запуска: `http://localhost:8000/docs`.

## Публичное визуальное демо

При публикации через GitHub Pages автоматически включается автономный демо-режим. Он не требует Python API: заказчик может войти, переключать светлую/тёмную тему и прокликать все основные экраны.

После push в `main` workflow `.github/workflows/deploy-pages.yml` собирает и публикует фронтенд.

## Возможности

- регистрация и вход с серверными сессиями;
- загрузка релизов и ручная модерация;
- принятие или возврат в черновик с причиной;
- ручной ввод UPC и ISRC после принятия релиза;
- очередь email- и in-app-уведомлений о модерации;
- ручное обновление статистики и финансов;
- запрос выплаты артистом по номеру карты и обработка заявки в админке;
- список кабинетов пользователей и блокировка нарушителей;
- новости и промо-раздел;
- питчинг релизов по форме промо-поддержки;
- промо-ссылки/smart links для артистов;
- встроенные тикеты поддержки и сообщения;
- роли владельца, администратора, модератора и поддержки;
- добавление и отключение администраторов владельцем.

## Supabase / продакшен

Фронт можно подключить к Supabase, но для этого нужны `SUPABASE_URL` и публичный `anon key`. Для продакшена также потребуется настроить таблицы, Row Level Security, хранилище файлов и отправку email-уведомлений.
