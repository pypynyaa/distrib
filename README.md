# Insomnia Market

Полноценный прототип музыкальной дистрибуции: React-интерфейс артиста и Python/FastAPI API с SQLite.

## Запуск

```bash
npm install
npm run dev
```

В отдельном терминале:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r backend/requirements.txt
uvicorn backend.main:app --reload --port 8000
```

Демо-аккаунты API:

- артист: `artist@insomnia.market` / `insomnia`
- владелец: `owner@insomnia.market` / `admin`

Документация API после запуска: `http://localhost:8000/docs`.

## Публичное визуальное демо

При публикации через GitHub Pages автоматически включается автономный демо-режим. Он не требует Python API: заказчик может войти, переключать светлую/тёмную тему и прокликать все основные экраны.

После push в `main` workflow `.github/workflows/deploy-pages.yml` собирает и публикует фронтенд.

## Возможности

- регистрация и вход с серверными сессиями;
- загрузка релизов и ручная модерация;
- принятие или возврат в черновик с причиной;
- очередь email- и in-app-уведомлений о модерации;
- ручное обновление статистики и финансов;
- новости и промо-раздел;
- встроенные тикеты поддержки и сообщения;
- роли владельца, администратора, модератора и поддержки;
- добавление и отключение администраторов владельцем.
